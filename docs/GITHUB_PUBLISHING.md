# GitHub Publishing Guide

The portfolio is published at [`usman78654/ecommerce-qa-testing-portfolio`](https://github.com/usman78654/ecommerce-qa-testing-portfolio) with `main` as its default development branch. The upstream ProShop Git metadata was removed before publication; its source URL and baseline commit remain recorded in the README and Attribution file.

## Recommended GitHub settings

- Description: `Evidence-driven e-commerce QA portfolio: manual, API, browser, accessibility, performance, and CI testing.`
- Topics: `software-testing`, `manual-testing`, `postman`, `playwright`, `accessibility`, `performance-testing`, `qa-portfolio`
- Default branch: `main`
- Enable Actions and issue templates.
- Do not publish `.env`, raw Newman JSON, cookies, password hashes, or real user data.

## Maintenance

Run the `QA Portfolio` workflow after material test changes and review its uploaded report artifact. Keep local secrets, runtime data, and dependency folders excluded through `.gitignore`.
