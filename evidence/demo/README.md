# Demo Video

`proshop-qa-walkthrough.webm` is an automated silent walkthrough that shows the
HTML evidence dashboard, a real product search, product detail, and cart journey.

Use [`docs/DEMO_GUIDE.md`](../../docs/DEMO_GUIDE.md) to record the polished
narrated version. The automated video is intended as a reusable visual asset and
proof that the walkthrough can be reproduced.
